# USB/IP ESP32 Add-ons for Home Assistant

## Add-ons

### [USB/IP ESP32 Client](./usbip-esp32-client)

Attach remote USB devices from ESP32-S3 USB/IP servers over WiFi to your Home Assistant instance.

## Installation

1. In Home Assistant, go to **Settings → Add-ons → Add-on Store**
2. Click the three-dot menu in the top right and select **Repositories**
3. Add this URL: `https://github.com/Xzatrox/ha-usbip-esp32-client`
4. Click **Add**, then refresh the page
5. The "USB/IP ESP32 Client" add-on will appear in the store
